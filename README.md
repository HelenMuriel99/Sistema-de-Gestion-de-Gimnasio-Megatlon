# Sistema-de-Gestion-de-Gimnasio-Megatlon

## Coordinación y seguimiento del proyecto

Esta rama contiene la documentación correspondiente a la **coordinación, planificación y seguimiento** del desarrollo del Sistema de Gestión de Gimnasio Megatlon.

Como Líder de Grupo, se realiza la organización de las actividades, asignación de responsabilidades, coordinación de los integrantes y seguimiento del avance del proyecto.

## Organización y Planificación

Esta sección contiene los documentos utilizados para organizar y controlar el desarrollo del proyecto:

* Cronograma de Actividades
* Tabla de Asignación de Tareas
* Tabla de Asignación y Seguimiento de Tareas
* Seguimiento de Avances
* Registro de Acuerdos y Reuniones

## Coordinación del Equipo

Las actividades de coordinación incluyen:

* Organización y distribución de tareas.
* Coordinación entre los integrantes del equipo.
* Seguimiento de las actividades planificadas.
* Control del cumplimiento de las tareas.
* Coordinación de entrevistas y reuniones.
* Seguimiento de revisiones y observaciones del proyecto.
* Comunicación de tareas pendientes y próximas actividades.
