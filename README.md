# Sistema-de-Gestion-de-Gimnasio-Megatlon

## 🏋️ Sistema de Gestión de Gimnasio Megatlon

Sistema integral para la **administración operativa, gestión de aforos por disciplinas, control financiero y registro de asistencia** para las cuatro sucursales del gimnasio **MEGATLÓN**.

El sistema busca centralizar y facilitar la gestión de los principales procesos del gimnasio, permitiendo organizar la información de clientes, planes, inscripciones, reservas, pagos y asistencias.

---

## 🎯 Objetivo del Sistema

Desarrollar un sistema de gestión que permita mejorar el control y administración de las operaciones del gimnasio MEGATLÓN, centralizando la información y facilitando el seguimiento de sus diferentes procesos.

---

## ⚙️ Funcionalidades Principales

* 👤 Gestión de clientes y usuarios.
* 🏋️ Gestión de disciplinas y espacios.
* 📅 Gestión de reservas y control de cupos.
* 💳 Administración de planes e inscripciones.
* 💰 Control de pagos y morosidad.
* 🚪 Registro y control de asistencia.
* 🏢 Gestión de las cuatro sucursales.
* 🔐 Control de acceso y autenticación de usuarios.
* 📊 Gestión y consulta de información administrativa.

---

## 📚 Estructura del Proyecto

El proyecto se encuentra organizado de acuerdo con las diferentes responsabilidades asignadas a los integrantes del equipo.

### 🔎 Analista

Contiene la documentación correspondiente al análisis y especificación del sistema:

* Levantamiento de requerimientos.
* Alcances y límites.
* Entrevistas.
* Requerimientos funcionales y no funcionales.
* Base de datos.
* Casos de uso.
* Historias de usuario.
* Documentación de revisión técnica.

### 👩‍💼 Líder

Contiene la documentación relacionada con la planificación y coordinación del equipo:

* Cronograma de actividades.
* Asignación y seguimiento de tareas.
* Seguimiento de avances.
* Reuniones y acuerdos.
* Control de tareas pendientes.

### 🎨 Dev Frontend

Contiene el desarrollo de la interfaz y funcionalidades correspondientes al lado cliente del sistema.

### ⚙️ Dev Backend

Contiene el desarrollo de la lógica del sistema, servicios, conexión con la base de datos y funcionalidades del lado servidor.

### 🧪 QA

Contiene las actividades relacionadas con pruebas, identificación de errores y verificación de las correcciones realizadas.

---

## 🔐 Funcionalidad de Login

Una de las funcionalidades actualmente desarrolladas es el **inicio de sesión**, trabajando de manera conjunta entre Frontend y Backend.

El proceso contempla:

* Ingreso de credenciales.
* Validación de campos.
* Autenticación del usuario.
* Comunicación entre Frontend y Backend.
* Validaciones correspondientes.
* Pruebas y correcciones mediante QA.
